§1

Overview

A user picks Buying only / Selling only / Both, then places lines directly on the chart. Each line is a standing order trigger: touch it, and the configured action fires. No manual re-arming — a line keeps firing on every touch until it expires on its own.

§2

Mechanics

One primitive, four flags

There's no separate "Entry line" / "SL line" / "Target line" object. Every line is the same thing: a 2-point segment (can be slanted) carrying any combination of 4 independent flags.

FlagOn touchQuantity
Buy EntryOpens a longLine's configured qty
Sell EntryOpens a shortLine's configured qty
Buy ExitCloses the open longWhatever's open
Sell ExitCloses the open shortWhatever's open

On one touch: exits fire before entries. An entry only fires while flat on that side — never long and short at once.

Mode = which flags are visible

ModeFlags exposed
Buying onlyBuy Entry, Buy Exit
Selling onlySell Entry, Sell Exit
BothAll four, independently, per line

"SL" and "Target" in Buying/Selling-only are just two lines both carrying the same Exit flag at different prices — whichever is touched first fires. Nothing structurally different between them.

Line lifetime

A line triggers from its 1st point's time through its 2nd point's time (interpolated price if slanted). Once the current time passes the 2nd point, it's dead — no more touches fire, regardless of price.

Drawing tool — trader use cases

Working reference, not part of the PRD. For each of the 46 verified v1 drawing tools: the distinct things a trader means when they ask for it, and what that implies for anchor-point resolution. Where a tool genuinely has only 2–3 real variants (mostly the niche Gann tools), it's left at 2–3 rather than padded to a fixed count.
